# WebNN instrumentation proposals

Working drafts for measuring WebNN from the web platform.

- [MLComputeTiming](webnn-ml-compute-timing-explainer.md) — engine-defined compute timing for graph
  compilation and execution, delivered as `PerformanceEntry` types on the Performance Timeline.
- [MLResourceCounts](webnn-ml-resource-counts-explainer.md) — resource accounting for a WebNN
  context (`MLContext.resourceCounts`).

**Discussion:** [webmachinelearning/webnn#963](https://github.com/webmachinelearning/webnn/issues/963)

**Status:** drafts, not W3C deliverables. They are written to be proposed to the Web Machine
Learning Community Group; the timing entry additionally needs a row in the Web Performance WG's
timing entry types registry. Nothing here has been adopted.
